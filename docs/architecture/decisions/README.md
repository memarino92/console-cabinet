# Architecture decision records

Use one numbered Markdown file per decision. Record **Context**, **Decision**, **Alternatives**, **Consequences**, **Status**, and **Date**. Status values: Proposed, Accepted, Superseded.

Only accepted choices belong in accepted ADRs. Chat brainstorming, candidate hardware, and price estimates are not decisions.
